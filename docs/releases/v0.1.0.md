## Limitações conhecidas

Estado de `origin/dev` em 2026-09-21; revisar contra o commit tagueado.

- Nenhum backend de modelo teve avaliação científica comparativa; as execuções reais registradas (SAM2/SAM3, DINOv2, CLIP, Qwen) têm escopos distintos e verificam contrato e comportamento, não qualidade do mapa.
- Não há geometria de referência confiável para o `corridor-02`, e o mapa geométrico validado usou a trajetória do dataset, não uma execução do FAST-LIO.
- A política de fusão ciente de qualidade continua opcional: nenhuma decisão foi tomada por falta de um run de fusão sobre dados reais.
- O PTv3 nunca foi executado; a justificativa do estágio opcional de point representation por avaliação controlada não existe.
- Os requisitos de tempo, VRAM, RAM e armazenamento dos backends reais não foram medidos de forma sistemática (#181).
- O CLI `contextmap` não traz os executores das capabilities reais: sem eles, um run real é bloqueado no preflight com uma mensagem explícita (PENDENTE: revisar quando a execução end-to-end, #177, estiver integrada).
- PENDENTE: acrescentar aqui o que ficar de fora entre entity resolution, spatial relations e `ContextMapArtifact`, conforme o que for integrado.
